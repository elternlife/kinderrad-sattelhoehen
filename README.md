# Sattelhöhen und Schrittlängen von 374 Kinderrädern und Laufrädern

Herstellerangaben zu Sattelhöhe (min/max), Mindest- und Höchst-Schrittlänge, empfohlener Körpergröße und Gewicht für 374 Kinderfahrräder und Laufräder von 25 Marken, die im Oktober 2026 in Deutschland erhältlich waren (315 Fahrräder, 59 Laufräder).

Jede Zeile nennt die Quelle (Herstellerseite, Herstellertabelle oder Hersteller-PDF), die Art der Messung und das Abrufdatum (08.10. bis 30.10.2026). Leere Felder bedeuten: Der Hersteller nennt den Wert nicht. Werte wurden weder umgerechnet noch geschätzt. Marken messen unterschiedlich (mit Schuhen, in Socken, barfuß), siehe Spalte `messart`.

Zusammengestellt von der Redaktion von [elternlife.de](https://elternlife.de/). Auf Basis dieser Daten rechnet der [Fahrradgrößen-Rechner](https://elternlife.de/rechner/fahrradgroesse/) aus der Schrittlänge eines Kindes die passende Radgröße und Sattelhöhe aus.

## Datei

`sattelhoehen-kinderraeder.csv` (UTF-8, Komma als Trenner, Dezimalpunkt)

| Spalte | Bedeutung |
|---|---|
| id | eigene Kennung |
| marke, modell | Hersteller und Modellname |
| typ | `fahrrad` oder `laufrad` |
| zoll | Radgröße in Zoll |
| sattel_min_cm, sattel_max_cm | niedrigste und höchste Sattelhöhe in cm |
| schritt_min_cm, schritt_max_cm | empfohlene Schrittlänge (Innenbein) in cm |
| koerper_min_cm, koerper_max_cm | empfohlene Körpergröße in cm |
| gewicht_kg | Gewicht laut Hersteller |
| messart | wie der Hersteller misst |
| modelljahr | soweit angegeben |
| quelle_url, quelle_art, abgerufen | Beleg und Abrufdatum |
| hinweis | Besonderheiten |
